# 功能目录（features.md）

## 新标签页行为

| 功能 | 状态 | 涉及文件 |
|:-----|:----:|:---------|
| 新开 tab 打开指定笔记（`new-tab-page`） | ✅ | `src/main.ts` |
| 新开 tab 触发指定命令（每日笔记/随机笔记/快速切换器等） | ✅ | `src/main.ts` |
| 关闭最后一个 tab 同样触发 | ✅ | `src/main.ts` |
| 打开模式控制（阅读/实时预览/源码模式） | ✅ | `src/main.ts` |
| 兼容模式（其他插件开新 tab 时延迟复查，避免误拦截） | ✅ | `src/main.ts` |
| 空路径/无效路径的 Notice 提示 | ✅ | `src/main.ts` |
